01 · Problem & users

Small factories can't see their own carbon.

Buyers, banks and regulators now ask MSMEs for a carbon number. Emissions stay invisible, and circular options are never evaluated because nobody can put a cost on them.

02 · Solution

Three steps. Two numbers. One plan.

Input what you burn, buy and throw away → detect the leak point → fix it with costed circular interventions.

1 · Input

What you burn, buy, throw away

3 short screens with presets for textile, foundry and food, so the demo never starts blank.

2 · Detect

Every source ranked

Sources ranked by tCO₂e. One chart makes the leak point obvious — usually a single boiler or grid power.

3 · Fix

Costed circular interventions

Sorted by payback. Add to plan for a before/after footprint, ₹ total, and an exportable report.

03 · How it works

Rules for the numbers, AI for the words.

Rules compute every ₹ and tCO₂e figure, so numbers stay auditable and explainable to a regulator. The LLM only writes the plain-language "why it works" notes.
